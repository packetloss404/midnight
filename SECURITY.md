# Security Policy

Report suspected vulnerabilities through the repository's
[private security advisory form](https://github.com/packetloss404/midnight/security/advisories/new).
If the form is unavailable to you, contact the repository owner without
including vulnerability details and ask for a private reporting channel via
the contact options on [`@packetloss404`'s profile](https://github.com/packetloss404).

Expected response targets:

- Acknowledge receipt within 3 business days.
- Triage confirmed severity within 7 business days.
- Coordinate disclosure target: 90 days unless active exploitation requires acceleration.

Do not file vulnerability details in public GitHub issues, pull request
comments, Discussions, or chat transcripts. Use public issues only to
ask non-sensitive process questions.

Do not include plaintext secrets, private keys, production tokens, or
exploit payloads beyond what is needed to reproduce. Redact hostnames,
tenant identifiers, and user data unless they are essential to the
report.

The `midn_` token prefix will be submitted to the GitHub Secret Scanning Partner Program before v1.0.
