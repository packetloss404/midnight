## Status model

- `IN PROGRESS`: repository work is actively being implemented.
- `READY`: repository-owned and unblocked.
- `OPERATOR`: needs credentials, infrastructure, or an explicit operator
  action; code work may continue independently where stated.
- `LATER`: intentionally outside the single-VM MVP.
- `DONE`: retained briefly when its closure prevents an old document from
  reopening the item.

An item closes only when its exit evidence is committed or linked here. A unit
test, planner, fixture, local route, or rendered configuration is not installed
or public proof. External evidence never substitutes for a repository test.
