# Repository context for Codex

Public documentation uses anonymized hostnames, IP addresses, and deployment
identifiers. For tasks that require the real operator environment, read the
local-only reports in `.midnight/publication-context/` when that directory is
available. They are intentionally excluded from Git and Docker build contexts.

Never copy identifying details from those reports into tracked files, commit
messages, pull requests, or public issue comments. Ask the operator before
publishing any host-specific evidence.
