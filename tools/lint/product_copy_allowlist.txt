# Product-copy allowlist.
#
# The product-copy guard (LINT_PRODUCT_COPY_GUARD_FAILED) fails when a string a
# person reads in the Midnight console uses implementation vocabulary:
# operation, durable, evidence, changeset, canonical, idempotency, admitted, or
# intake. The translation table lives in
# docs/railway-ux-9-of-10-target-2026-09-01.md; the rule is in
# docs/contributing/style.md.
#
# Every line below is one deliberate exception. Format:
#
#   <repo-relative path> | <exact user-visible text, whitespace collapsed>
#
# Entries are exact. Rewording the string retires its own exemption, and the
# guard fails on an entry that no longer matches anything, so this file cannot
# quietly outlive the copy it excuses.
#
# `#` lines are comments and blank lines are ignored. web-next/src/pages/docs/**
# is excluded by path: the in-app documentation teaches the control-plane model,
# so those terms are its subject rather than leaked jargon.
