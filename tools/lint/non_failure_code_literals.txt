# Non-failure-code literals.
#
# Tokens listed here are SCREAMING_SNAKE_CASE string literals that the
# deep-registry guard would otherwise treat as missing failure codes. They are
# not failure codes — they are environment-variable names, kernel capability
# names, TLS cipher suite names, internal issue codes consumed by other parts
# of Midnight, and similar strings whose presence in source must not require a
# row in docs/error-codes.md.
#
# Format: one token per line. `#` lines are comments. Blank lines are ignored.
#
# Adding a token here is intentional: the alternative is a per-line
# `// not-a-failure-code` annotation in the source file. Prefer the inline
# annotation when the literal is owned by a single line; use this file only
# when the literal is shared, lives in a forbidden package the lint lane
# cannot edit, or is defined by an external standard.
